# Claude 연결과 OCR 없는 이미지 추출

운영 환경은 `AI_PROVIDER=claude`, `CLAUDE_MODEL_ID=claude-sonnet-5-5`,
`CLAUDE_VISION_ENABLED=true`, `CLAUDE_CART_MODE=direct`,
`CLAUDE_THINKING_MODE=between_tools`, `CLAUDE_EFFORT=low`,
`DIRECT_CART_OUTPUT_MODE=schema`를 사용합니다. API 키는 서버 Secret에만 둡니다.
`ANTHROPIC_API_KEY`도 지원하지만 `CLAUDE_API_KEY`가 우선합니다.

## 기능별 처리

| 기능 | Claude에 보내는 입력 | OCR | AI의 역할 |
| --- | --- | --- | --- |
| 장바구니 사진 | 축소한 이미지 한 장 | 없음 | 체크 여부·상품명·가격·사진 좌표 추출 |
| 상품명 분류 | 이름·가격 텍스트 | 없음 | 카테고리와 초안 질문 문구 |
| 상품 URL | 서버가 HTML에서 읽은 이름·가격 | 없음 | 텍스트 상품 분류; URL 수집은 기존 서버 기능 |
| 구매 전 일일 질문 | 서버가 고른 질문 유형·상품 정보·맥락 | 없음 | 선택된 유형을 유지하며 짧은 상품별 문구 생성 |
| 관찰 종료 요약 | 사용자가 제출한 로컬 답변·서버 집계 | 없음 | 근거에 맞는 요약 문구; 숫자는 서버 규칙대로 유지 |
| 구매 후 점검 | 해당 없음 | 없음 | AI 미사용. 구매 14일 후 사용일수 한 번 점검 |
| 할인 계산 | 해당 없음 | 없음 | AI 미사용. 입력한 할인·배송 조건으로 계산 |

할인 조건 사진 추출 함수도 Claude 설정에서는 이미지 직접 호출만 하고 OCR로
되돌아가지 않습니다. 다만 현재 프런트 `parseDiscountRules`와 공개 API에는 이 함수가
연결되어 있지 않으므로, 할인 사진 자동 분석이 활성화되었다는 뜻은 아닙니다.

최신 main의 질문 정책을 보존합니다. 서버가 상품 적합성·최근 질문·노출 횟수에 따라
유형을 고르고 Claude가 문구를 개인화합니다. Claude가 유형이나 답변 의미를 바꾸면
검증에서 거부합니다. ‘예’ 한 개를 원래 관찰 기간 내 예상 사용 하루로 집계하며,
14일/30일로 재환산하지 않습니다. 구매 후 반복 AI 질문은 다시 켜지 않습니다.

## 장바구니와 프런트 호환

직접 추출은 이미지 검증·축소 → Claude 한 번 → JSON/값/좌표 범위 확인 → 원본 사진
크롭 순서입니다. 전체 OCR, 가격 OCR, 항목별 재검증과 자동 재시도는 없습니다.
사진은 생성하지 않고 원본을 잘라냅니다. 불명확한 체크는 `review_items`, 읽지 못한
필드는 `review_fields`로 반환합니다. 시간 초과·잘린 출력·잘못된 JSON은 수동 확인으로
반환하며 OCR 또는 Lablup으로 자동 전환하지 않습니다.

사진 추출 요청에서는 카테고리·일일 질문을 생성하지 않습니다. 호환 필드에 넣은
`OTHER`/`FALLBACK`은 프런트에서 미분류 상태로 처리하여 기존 확인 화면의 텍스트
카테고리 추천을 사용합니다. 이 추천도 Claude 호출이지만 사진 추출과 별도 단계이며
OCR은 쓰지 않습니다. 사용자가 선택한 카테고리와 체크 불명확 항목의 기본 제외 상태를
보존합니다. 일일 질문은 기존대로 관찰 당일 생성하고 기기에 저장합니다.

## 실패 처리와 명시적 비교 설정

Claude 실패 시 상품 분류·질문·요약은 기존 키워드/기본 문구를 사용할 수 있습니다.
이는 로컬 대체 처리이며 다른 AI 공급자 호출이나 OCR은 아닙니다. 키 누락을 감추기
위해 Lablup 키를 대신 사용하지 않습니다.

이전 경로와의 명시적 비교를 위해 `AI_PROVIDER=lablup`, `LABLUP_CART_MODE=verified`와
OCR 코드·빌드 의존성은 보존합니다. `CLAUDE_CART_MODE=verified`도 개발 비교 전용으로
남아 있으나 운영에서는 사용하지 않습니다. 운영 환경변수를 바꾸면 재배포해야 합니다.
Lablup도 `LABLUP_CART_MODE=direct`, `LABLUP_VISION_ENABLED=true`로 직접 추출할 수 있습니다.
`DIRECT_CART_OUTPUT_MODE=prompt`는 양쪽 API의 JSON 강제 옵션을 끄는 비교용 설정입니다.

2026-11-01 같은 사진 3장 × 3회, 같은 이미지·프롬프트·출력 한도 4096·OCR 0회 비교에서
Claude 중앙값은 2.384초(전체 검사 9/9), 기존 모델은 10.959초(3/9)였습니다.
기존 모델은 5회 출력 한도 초과, 1회 사진 영역 검사 실패였습니다. 작은 회귀 표본과
로컬 서비스 호출의 결과이며 업로드·배포 서버 지연과 일반적인 인식 정확도를 보장하지 않습니다.

## 검증

`python -m scripts.check_ai --provider claude`는 고정 텍스트와 생성 숫자 이미지로 연결을
확인합니다. 실제 사용자 자료를 쓰지 않으며 요청 시간·토큰 수·성공 여부만 출력합니다.
`tests/test_claude.py`와 `tests/test_direct_cart.py`는 공급자 선택, 서버가 선택한 질문 유형
보존, 모델 기록, 원본 필드 보존, 이미지 오류 시 OCR/재시도 차단을 모의 API로 검사합니다.
로그는 모델·시간·토큰 수만 남기며 키·이미지·질문/답변 원문은 남기지 않습니다.
